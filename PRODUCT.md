# PaperBridge Product Context

## What This Is

PaperBridge is a private, native macOS academic paper reader. It opens PDFs or pasted text, preserves original document context, and uses local Ollama models for translation, summary, explanation, and selected-text research tools.

## Users

Researchers, students, and technical readers who work across languages and want paper analysis to remain on their own Mac.

## Core Jobs

- Open and preserve academic PDFs with PDFKit, with optional MinerU structured extraction.
- Read source and translated paragraphs in a clear bilingual sequence.
- Preserve figures, tables, formulas, captions, and document hierarchy when structured parsing is available.
- Translate or explain selected text, save highlights and notes, summarize the paper, and export Markdown locally.

## Principles

- Local first: papers and model requests stay on the user's Mac.
- Reading first: typography and document context take priority over dashboard density.
- Honest fallbacks: exact PDF facsimile remains available when OCR or MinerU is unavailable.
- Native behavior: keyboard access, selection, inspectors, settings, and window resizing follow macOS conventions.

## Visual Direction

Match paperbridges.net: warm paper reading surfaces, deep ink navigation, cobalt primary controls, coral translation accents, and an editorial serif/sans hierarchy. Use solid color planes rather than gradients or decorative glass.

## Platform

adaptive

Current shipped platform: native macOS desktop.
