The 0.2.10 release passed **154 unit tests**, the production build, **23 desktop suites**, and packaged startup. Both public downloads matched their SHA-256 checksums. On the RX 7800 XT, the public Portable build adjusted the text preview of a 15-page paper, translated an introductory paragraph via ROCm, reset appearance with the original PDF geometry intact, and restored the translation and appearance after restart. Earlier tests on the same machine resumed six pending full-paper excerpts and exported all 15 original page PNGs and the byte-identical PDF. The OpenAI transport is tested with controlled responses. ## GPU behavior

The Windows port detects video adapters, NVIDIA CUDA driver capability and Ollama's running-model VRAM use. On x64, managed MinerU 4.1.7 uses ONNX with DirectML or CPU. Eligible NVIDIA fresh installations retain the managed 3.4.5 CUDA path, with a runtime check and legacy pipeline fallback. RX 7800 XT logs confirm DirectML layout and text recognition, CPU detection, and full VRAM placement of the Ollama 4B model through ROCm. [AMD device report](AMD_DEVICE_TEST.md)
