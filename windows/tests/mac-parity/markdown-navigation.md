## Thermal measurements

| Stage | Observation |
| --- | --- |
| Baseline | Record the baseline voltage using the reference electrode before adding the sample to the measurement chamber. |
| Insulation | Verify that the leads remain isolated when the instrument is attached to the sample holder. |
| Conditioning | Hold the sample at the starting temperature until the reference sensor reading stabilizes. |
| Reference | Measure the response of the reference material for comparison with subsequent observations. |
| Calibration | Calibrate the instrument before increasing the load and retain the original calibration values. |
| Heating | Increase the temperature in small increments and pause between readings to allow thermal equilibration. |
| Plateau | Maintain the same load while the sample approaches its maximum operating temperature. |
| Control | Repeat the measurement without changing the temperature, pressure or mounting arrangement. |
| Cooling trace | Record the first response after the heater is turned off and compare it to the reference reading. |
| Recovery | Inspect the response after cooling and record how long it takes for the baseline to stabilize. |
| Repeat | Record a second cycle under the same conditions and compare readings across the complete range. |
| Inspection | Inspect the sample surface after the final measurement and document any visible changes. |
| Archive | Save the complete sequence together with the calibration record and acquisition temperature. |
