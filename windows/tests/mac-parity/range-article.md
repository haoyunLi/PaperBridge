# Temperature validation

The notebook describes an independent measurement study.

## Abstract

Three sensors were calibrated before the experiment.

## Methods

We tested each sensor in a temperature chamber.

| Sensor | Temperature |
| --- | --- |
| A | 18 |
| B | 24 |

Each chamber was checked against an independent thermometer.

## Results

The reference and chamber temperatures agreed at both settings.

The second sensor took longer to equilibrate.

## Conclusions

Independent calibration improved repeatability across the three sensors.
