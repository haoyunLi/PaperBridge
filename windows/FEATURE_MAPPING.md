# PaperBridge macOS 1.10.0 与 Windows 0.2 功能逐项映射

论文自带的便笺、带留言的高亮和下划线可在两个原 PDF 视图中打开。作者和留言来自文件，Research Inspector 仅保存自己的笔记。[原生和 Windows 对照](tests/pdf-comments-e2e.cjs)

原 PDF 的命令链接已用同一份维修记录在 PDFKit 和 Windows 打包版核对。首页、末页、前后翻页和前后阅读位置均到达同一页。跨两行且中间隔有正文的 DOI 只响应两个引用片段。[实机对照](tests/pdf-named-actions-e2e.cjs)

当前验收目标是功能与可执行操作的一对一对应；排版按 Windows 字体、窗口大小及显示缩放适配。Mac 的尺寸和间距作为设计参考，不以像素一致作为功能对齐的条件。

截至 2026-11-27，固定基线共 111 项，**108 项对齐、3 项部分对齐**。RX 7800 XT 的 4B、12B 和 27B 都已实际翻译并重开保存的论文。4B 和 12B 另核对了温度、电压、统计学否定和 p 值。余项为 NVIDIA 真机解析、更新安装流程和 Windows 发布者签名。[模型对照实测](AMD_DEVICE_TEST.md)。此计数只覆盖表内功能。全新 Windows 从 GitHub 下载并打开了两种 EXE，看到了便携版解压提示和首次引导。旧客户端在保存书签与笔记后将已校验的新版安装包交给 Windows。[公开下载验收](https://github.com/haoyunLi/PaperBridge/actions/runs/45172227052/job/137692363583) · [应用内更新验收](https://github.com/haoyunLi/PaperBridge/actions/runs/45172227052/job/137694169199)

首次审计的固定基线：macOS 1.9 commit `73951d9` 与本分支 `windows/` 的 0.2 实现，核对日期 2026-09-20。共 111 项：**43 对齐、68 部分、0 缺失**。本表按**用户可执行的动作与可观察的结果**拆分；同一行出现入口只代表有代码路径，不代表结果已经等价。`对齐`指静态代码核对显示主要行为等价，`部分`指有可用路径但缺少列出的行为，`缺失`指没有对应路径。[AMD 真机报告](AMD_DEVICE_TEST.md)已覆盖一台 RX 7800 XT、真实翻译、一篇复杂论文，以及单页图像型扫描 PDF 的 OCR 和译文；Electron 回归另覆盖重复文字、双页 PDF 同词不同标注、无文字层 PDF 的 OCR 引导、空 MinerU 结果降级、逐论文任务设置、导出及重启恢复。其它硬件、复杂扫描件、Mac 逐项对照和正式签名仍需验证。

## Windows 特有的硬件映射

Windows x64 的 MinerU 4.1 走 ONNX DirectML 或 CPU。具备适配驱动的 NVIDIA 新安装仍可使用 MinerU 3.4.5 和 `cu126`/`cu128` PyTorch CUDA。Settings 分开报告 MinerU Auto 选择与 Ollama `/api/ps` 的显存使用。RX 7800 XT 的实际解析日志已确认版面分析、文字识别使用 DirectML，翻译模型通过 ROCm 完整驻留显存。模型建议会排除 Windows 标记故障或停用的适配器。双 AMD 真机上分别识别出 16 GiB 和 512 MiB，建议使用 12B。NVIDIA CUDA 仍待真机验收。

## 实施顺序和完成标准

1. **P0：阅读和数据正确性** — A07–A09 自动解析策略；A19 参考文献过滤；B04 三种阅读模式；C15 结构化全文译稿；D03–D06 精确证据；E03/E11/E15/E17 标注锚点；F07 MinerU 编辑保护；G05 完整导出。任一项“对齐”须有 Mac 同一用户流程与 Windows 结果对照。
2. **P1：1.9 小功能** — 拖放、练习论文不误替换、跨页修复、质量警告、搜索位置、任意章节/队列插队、整段解释与独立语言、术语搜索、编辑/撤销、图书馆标签和多视图位置。
3. **P2：交付与体验** — 剩余快捷键验收、安装器签名与正式更新安装、更多 DPI 和设备兼容性；Settings 推荐卡片和 MinerU 自动发现入口已实现并纳入回归。

关闭某一行前，至少使用同一份普通 PDF、双栏 PDF、扫描 PDF、含公式/图片的 MinerU PDF 和粘贴文本做 Mac↔Windows 行为核对；保存、关闭、重启、取消任务、切换论文、导出后复查结果。GPU 安装流程另需 NVIDIA、AMD、纯 CPU 设备分别验收。这里的状态是代码审计结论，并非这些真实设备验收已经完成。
